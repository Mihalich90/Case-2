Что демонстрирует программа
Демонстрация	Где показано
Конструктор базового класса	Transport.__init__
Вызов super().__init__()	Car.__init__ → сначала базовый, потом свой
Переопределение метода (override)	move() и info() в Car
Вызов базовой версии через super()	super().info() внутри Car.info()
Собственный метод потомка	honk() — есть только у Car
Полиморфизм	список vehicles — у каждого своя move()
isinstance / issubclass	проверка отношений наследования
Ключевые моменты (шпаргалка)
super().__init__(...) — обязательно, если нужно инициализировать поля базового класса, иначе они не создадутся.

Переопределение — метод потомка с тем же именем «закрывает» базовый.

super().method() — вызывает базовую версию переопределённого метода (расширение, а не замена).

Полиморфизм — один интерфейс (move()), разное поведение в зависимости от типа объекта.

Собственные методы потомка недоступны объектам базового класса (t.honk() вызовет AttributeError).
